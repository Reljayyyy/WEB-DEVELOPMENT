# 🏫 School Announcement & Dashboard Portal

A modern, responsive web application built with **Laravel**, **React (Inertia.js)**, and **Tailwind CSS** designed to streamline campus communication, event management, and academic tracking for students, faculty members, and administrators.

---

## ✨ Core Features

*   **Role-Based Portals & Views**: Switch seamlessly between **Student**, **Faculty**, and **Administrator** views to experience tailored dashboard metrics and permissions.
*   **Dynamic Announcement Board**: Real-time campus notice board featuring category filters (*Academic, Events, Administrative, Sports*), search functionality, and urgent alerts.
*   **Event RSVP System**: Interactive calendar and events module allowing users to browse upcoming seminars/fests, check capacity limits, and confirm or toggle attendance (`RSVP Now`).
*   **Modern Authentication & UI**: Redesigned clean authentication flows (Login/Register) featuring secure password visibility toggling, custom card layouts, and complete removal of default boilerplate logos.
*   **Quick Portal Links**: Fast access to academic utilities including Grade Transcripts & Audits, Class Timetables & Room Allocations, and Library Bookings.

---

## 🛠️ Technology Stack

*   **Backend**: Laravel (PHP framework)
*   **Frontend**: React.js with Inertia.js (Single Page Application bridge)
*   **Styling**: Tailwind CSS
*   **Database**: MySQL (`fe_marrie`)
*   **Asset Bundling**: Vite

## 🚀 Getting Started & Installation

Follow these steps to run the project locally on your machine:

### Prerequisites
Make sure you have the following installed:
*   PHP (>= 8.2) & Composer
*   Node.js & npm
*   MySQL Server (via WampServer, XAMPP, or independent service)

### 1. Clone the Repository & Install Dependencies
Open your terminal (e.g., VS Code integrated terminal) and run:

# Install PHP dependencies
